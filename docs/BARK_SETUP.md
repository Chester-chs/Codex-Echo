# iPhone 接入 Bark

[English](BARK_SETUP.en.md) | **简体中文** · [返回 README](../README.zh-CN.md)

推荐使用此方式，最简单，无需 GitHub 账号或服务器。

## 1. 准备 Bark

通过 [Bark 官方项目](https://github.com/Finb/Bark) 的 App Store 链接安装，打开并允许通知。在 **iPhone 设置 → 通知 → Bark** 中勾选 **锁定屏幕**。

复制 Bark 中的推送地址，格式类似 `https://api.day.app/YOUR_DEVICE_KEY`。请用自己的真实地址，不要复制示例；目前只支持默认的 `api.day.app` 服务。地址请保密。

## 2. 绑定并保存

打开 [Codex 回响](https://echo-radar.pages.dev/)，在 Tibo 推文列表下方展开 **手机云端提醒**：

1. 粘贴 Bark 地址。
2. 选择 **重置公告** 和／或 **来源预测**。
3. 设置预测阈值（40%–90%）及推送语言。
4. 点击 **绑定并保存**，确认出现已绑定状态。

阈值只影响预测提醒。识别到重置计划和对应完成证据时分别提醒，重复确认会去重；首次绑定不补发历史消息。

## 3. 测试锁屏通知

点击一次 **发送测试通知**，随后关闭网页并锁屏，通常约一分钟到达。请确认锁屏实际出现消息；“Bark 已接受”不等于手机已收到。测试间隔为 10 分钟。

**设置完成后，网页和电脑都可以关闭。** 手机需联网并允许通知。页面提醒是另一项功能，必须保持页面运行。

## 修改或停止

- 修改后点击 **保存提醒设置**。
- 关闭两类提醒并保存可暂停；选择 **退订并删除地址** 可停止并移除地址。已经在发送的通知可能仍会到达。
- 更换浏览器后，再次粘贴同一地址可恢复管理，原浏览器的管理权限会被替换。

## 没收到怎么办

- 检查 Bark 锁屏权限、专注模式和通知摘要。
- 在网页刷新状态；若请求失败，核对地址。
- 测试成功后，仍需出现新的符合条件的消息才会自动提醒。
- 同一手机不要同时运行网页订阅和 GitHub 提醒，避免重复。

共享服务目前支持 30 台设备，每台按 UTC 日期每天最多 20 次发送尝试，包含测试和重试。名额已满时，可选用 [GitHub 自助提醒](GITHUB_BARK.md)。
